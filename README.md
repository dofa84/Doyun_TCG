# DOYUN TCG · 카드 공방

React + TypeScript 웹 어드민과 Cloudflare Worker / D1 API. R2 구독은 필요하지 않다.

## 로컬 실행

Node 22 이상 권장.

```sh
npm ci
npm run build
npm run db:local
npm run worker:dev
```

http://127.0.0.1:8787 에서 가입 후 사용. 개발 중 React 빠른 새로고침은 별도 터미널에서 `npm run dev`를 실행하고 http://127.0.0.1:5173 접속. API 요청은 로컬 Worker로 전달한다.

회원가입 후 관리자 지정:

```sh
npm run admin:local -- your-email@example.com
```

개발 DB는 `.wrangler/state`에 보관되며 운영 DB와 별개다. 로컬 비밀번호나 테스트 계정은 Git에 포함되지 않는다.

### 관리자 아이디 로그인

로그인은 이메일 또는 운영자가 지정한 아이디를 받는다. 회원가입은 계속 이메일 기반이다.

운영 관리자 생성:

```sh
node scripts/bootstrap-admin.mjs --remote --login admin --generate
```

비밀번호는 생성 시 .local 폴더의 권한 600 파일에만 기록하며 콘솔에 출력하지 않는다. 같은 아이디의 기존 계정은 덮어쓰지 않는다. 로컬 생성은 --local을 사용하고 비밀번호를 표준 입력으로 전달한다. 운영에서는 12자 미만 비밀번호를 거부한다.

## 구현 범위

- 가입·로그인·로그아웃, 서버 세션, user/admin 권한
- 공유 진영 목록·생성·소유자 수정
- 카드 제작·수정·보관, 서버 수치 검증, 사진 업로드
- 심사 요청·승인·반려·사용 활성화/중지, 변경 기록
- 승인 카드 수정 시 재심사·사용 중지, 버전 충돌 방지
- 진영별 엑조디아 최대 5장 (DB 제약 포함)
- 승인·활성 카드 20장 이상 + 엑조디아 5장 준비 표시
- 모바일웹 대전: 서로 다른 두 계정의 순차 로그인 후 한 기기 교대
- 서버 고정 덱: 엑조디아 5 + 비엑조디아 랜덤 15, 시작 시 수치·효과·사진 참조 고정
- 오픈/공격 택1, 수비자 피해 카드 선택, 자리 교환 공격, 사망 보충, 엑조디아/전멸 승패
- 패시브3·특수3 효과, 특수 게임1회·재생3회, 새로고침 복원·중복 요청 차단
- 카드 수치 비교. 승률·수치 밸런스 검증은 아직 제공하지 않음

## 한 기기에서 대전하기

1. 서로 다른 계정 두 개를 준비한다. 일반 가입은 이메일 기반이며 관리자 권한 없이 게임할 수 있다.
2. 승인·활성 카드 20장 이상, 엑조디아5장인 진영이 필요하다. 같은 진영을 두 사람이 선택할 수 있다.
3. 첫 계정 로그인 → 대전 메뉴 → 진영 선택 → 대기방 만들기.
4. 대기방에서 두 번째 계정으로 전환 → 진영 선택 → 참가. **중간에 로그아웃하지 않는다.**
5. 화면의 기기 교대 안내에 따라 오픈/공격·수비 대상을 선택한다. 매 턴 비밀번호를 요구하지 않는다.
6. 새로고침은 같은 게임을 복원한다. 로그아웃/세션 만료 후에는 원래 두 계정으로 기기를 재인증한다.

대전 쿠키는 해당 게임만 허용하고 일반/관리자 로그인 권한으로 사용할 수 없다. 실제로 기기를 넘겨받은 사람이 누구인지는 인증하지 않는 가족 공유 기기용이다. 온라인 매칭·랭킹·두 기기 실시간 대전은 제공하지 않는다.

응답 유실 요청은 계정별 탭 임시 저장으로 유지하며 메뉴 이동/새로고침 후에도 같은 request_id로 재확인한다. 비밀번호·쿠키·비공개 카드 정보는 임시 저장하지 않는다. 종료 결과는 상대 재인증 없이 참가자 개인 로그인으로 조회한다. 공개 로그 UI는 첫50개 행동 표시까지이며 후속 페이지 UI는 미구현이다.

## 검증

```sh
npm run verify
```

Miniflare D1에서 인증·소유권·사진 저장·심사 전환·동시 요청을 통합 검증한다. E2E 실행은 `docs/runbook.md` 참고.

## 운영 연결

`wrangler.toml`의 database_id는 실제 운영 D1, preview_database_id는 기존 로컬 데이터 식별자다. 마이그레이션 0005까지 적용한 뒤 배포한다. 설치 패키지는 lockfile로 고정한다. 원격 생성·배포·관리자 지정은 [운영 문서](docs/runbook.md) 참고.

사진은 기기에서 긴 변 최대 1200px·512 KiB 이하로 압축한 뒤 D1에 저장한다. 선택 가능한 원본은 PNG/JPEG/WebP 10 MiB 이하이며 원본은 서버에 저장하지 않는다. 가족 테스트용 무료 한도 설계이며, 무제한 저장·요청을 보장하지 않는다.

세션은 7일 만료, 비밀번호는 PBKDF2-SHA256 100,000회로 해시, 인증 시도는 IP별 15분 30회 제한. 운영 HTTPS에서는 Secure 쿠키를 사용한다. 이메일 확인/비밀번호 찾기는 미구현이며 가족·초대 테스트 범위에서 사용한다. 공개 운영 시 해당 기능과 가입 정책을 재검토해야 한다.

패시브 3종·특수 공격 3종을 family-v1 전투 엔진에 연결했다. 효과별 대상/순서는 승인 설계에 정의하며 수치 밸런스는 미검증이다.
