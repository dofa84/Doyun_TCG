# 운영 및 검증

## Cloudflare 연결 순서

1. 기존 Worker의 실패 빌드 로그와 실제 빌드 설정 확인.
2. D1 `doyun-tcg-db` 생성 또는 기존 리소스 확인. R2는 사용하지 않는다.
3. D1 ID를 wrangler.toml에 입력. 바인딩명은 DB.
4. 운영 마이그레이션: `npx wrangler d1 migrations apply DB --remote`.
5. 빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy`, 루트 경로는 저장소 루트.
6. workers.dev 또는 별도 도메인 활성화. API와 정적 웹은 같은 Worker에서 제공.
7. 운영 가입 후 D1에서 대상 계정만 관리자 승격. 비밀번호·세션 원문을 로그에 기록하지 않는다.
8. 실제 로그인·카드 저장·이미지 조회·심사·진영 준비 조건을 운영에서 별도 확인.

2026-10-16 사용자가 무료 방식으로 변경을 승인하여 R2 바인딩을 제거하고 D1 사진 저장으로 전환했다. 마이그레이션 0004는 기존 테이블을 삭제하지 않고 이미지 바이트 테이블을 추가한다. 운영 DB에는 전환 당시 사진이 없었으며, 로컬 기존 사진 1개는 바이트 일치 확인 후 이전했다. 기존 로컬 R2 원본은 삭제하지 않았다. 최종 운영 검증 상태는 STATUS.md를 참고한다.

Cloudflare Workers Builds를 배포 주체로 사용하고 GitHub Actions는 검증 전용으로 유지한다. 중복 배포 파이프라인을 만들지 않는다.

## 로컬 UI 확인

`npm run build && npm run db:local` 후 `npm run worker:dev` 실행.

Playwright E2E는 localhost:8799와 별도 .wrangler/e2e 저장소에서 새 테스트 계정을 생성하고 로그인·진영 생성·사진 업로드·카드 저장 흐름을 확인한다. 기본 미리보기(8787)의 DB와 운영 데이터에는 접근하지 않는다. 브라우저가 없으면 먼저 npx playwright install chromium을 실행한다.

```sh
npx playwright test
```

## 이미지 정책

원본 PNG/JPEG/WebP 10 MiB 이하를 브라우저에서 디코딩하고 긴 변 1200px·512 KiB 이하로 재인코딩한다. 서버는 512 KiB 제한과 MIME·파일 서명을 독립적으로 확인한다. 서버 전체 디코딩은 아직 없으므로 직접 API 호출의 손상 파일까지 검증한다고 설명하지 않는다. 이미지 바이트는 별도 D1 image_data 테이블에 보관하고 카드 목록에서는 읽지 않는다. API가 제작자/관리자 또는 승인·활성 카드 여부를 확인한다. 카드 참조 중인 이미지 삭제는 차단하며 미참조 사진 삭제 시 메타데이터와 바이트를 함께 제거한다. 미사용 업로드 자동 정리는 후속 과제다.

무료 플랜의 저장·일일 요청 한도는 그대로 적용된다. 다른 프로젝트의 계정 사용량도 고려해야 하며 무료 한도 초과 시 정상 동작을 보장하지 않는다. 유료 플랜 전환·R2 가입·OpenAI 연결은 이 변경에 포함하지 않는다.

## 범위와 미완료

두 계정 한 기기 전투·덱 DB 고정·재접속 복원을 구현했다. 운영 반영은 STATUS.md 확인. 실제 승률/밸런스 분석·온라인 매칭·랭킹은 미구현이다.

## 게임 배포 및 검증

마이그레이션0005는 기존 카드/계정을 삭제하지 않고 게임 관련5개 테이블만 추가한다. 새 Worker 배포 전 로컬/운영 대상 DB를 확인하고 적용한다. 게임 사진 참조 테이블이 없으면 새 이미지 권한 쿼리가 실패하므로 순서를 바꾸지 않는다.

대전 참가자는 각자 가입해야 한다. 관리자 계정으로 상대 인증을 대신하지 못한다. 첫 로그인으로 방을 만들고, 로그아웃 대신 두 번째 계정으로 로그인·참가한다. 일반 로그인 쿠키는 두 번째 계정으로 바뀌지만 별도 대전 쿠키와 원래 두 세션이 해당 게임의 양쪽 행동을 허용한다. 명시적 로그아웃은 원래 세션을 삭제하여 대전 권한도 무효화한다. 재접속 복구 시 참가자별 로그인·이 계정 인증을 수행한다.

모바일 플레이어는 `/play`로 접속한다. `/`는 카드 제작·관리 화면이며 대전 메뉴는 `/play`로 이동한다. 기존 `/?game=<id>` 링크는 `/play?game=<id>`로 전환한다. 로그인·회원가입·계정 전환은 동일 인증을 사용한다.

대전 쿠키는 /api/games/<id> 경로, HttpOnly, SameSite Strict, HTTPS Secure, 최대7일이다. 비밀번호/토큰 원문을 게임 데이터·URL·JS 저장소·로그에 넣지 않는다. 실제 기기 교대자 신원까지 보증하지 않는다.

게임용 E2E는 .wrangler/e2e에만 합성 계정·20장 승인 카드·사진을 만든다. 기본 로컬 DB와 운영 DB에는 자동 시드하지 않는다. 운영 대전 검증을 위해 데이터/계정이 필요하면 먼저 사용자 승인을 받는다. 운영 준비 조건이 없으면 그것을 제품 구현 실패와 구별해서 보고한다.

게임 이벤트 API는 after 버전으로 최대50행 조회. 공개 버림은 수만 제공하며 덱 순서/미공개 카드명은 서버에만 남는다. 게임의 사진 참조는 오래된 이미지 삭제를 차단한다. 게임 이력/미사용 이미지 자동 삭제는 아직 없으므로 D1 무료 저장 한도를 관찰한다.

미확정 요청은 계정별 탭 sessionStorage에 공개 식별자/행동만 저장한다. 메뉴 이동·새로고침 후 같은 ID로 재확인하며 새 요청은 차단. 저장이 차단되면 서버로 전송하지 않는다. 탭을 닫으면 탭 저장도 사라지므로 기존 대기방/게임 목록을 먼저 확인한다. 실제 계정 인증 정보·토큰·카드 스냅샷은 브라우저 저장에 넣지 않는다. 종료된 결과는 개인 로그인으로 읽을 수 있고, 두 계정 재인증은 진행 게임의 행동에만 필요하다.
